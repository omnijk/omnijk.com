## ⚙️ 技术栈

- 框架：**Next.js 14 App Router + React 18**
- 样式：**Tailwind CSS**
- 动画：**Framer Motion**
- 图表：**ECharts**
- 内容：**本地 MDX**（`gray-matter` + `next-mdx-remote`）
- 部署：**Vercel** 或 Node.js standalone

项目不依赖数据库、CMS、认证服务，也不需要 `.env`。博客、项目、经历和技术栈数据全部随代码一起维护。

## 📁 项目结构

```text
app/                 页面路由
content/blog/        博客 MDX 文章
components/          页面组件
lib/blog.js          读取和解析 MDX
lib/project.js       项目数据
lib/toc.js           目录标题提取
public/              图片、图标、字体
```

## 💡 本地开发

### 环境要求

- Node.js 18.18 或更高版本

### 克隆与安装

```bash
git clone https://github.com/omnijk/omnijk.com
cd omnijk.com
npm install
```

### 启动

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 🚀 生产构建

```bash
npm run build
npm start
```

`npm run build` 会生成 `.next/standalone` 独立部署目录，`postbuild` 会自动把静态资源和 `content` 复制进去。`npm start` 直接运行 standalone 服务，默认端口为 3000，可通过 `PORT` 环境变量修改。

> 构建前必须先停止 dev server。两者共用 `.next` 目录，同时运行会破坏开发服务器的构建产物。

## ✍️ 内容维护

### 新增博客

在 `content/blog/` 下新建 `.mdx` 文件，frontmatter 支持：

```yaml
title: 文章标题
summary: 文章摘要
image: /images/cover.png
author: omnijk
publishedAt: '2026-01-01'
tag: 前端
```

正文使用二级、三级标题，右侧目录会自动生成。

### 修改项目与经历

- 项目列表：`lib/project.js`
- 个人经历：`app/message/page.js`
- 首页技能：`components/SkillsBar.jsx`
- 技术栈页面：`components/TechStackRadar.jsx`
